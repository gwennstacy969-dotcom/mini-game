📖 Cara Bermain RiYooIQ

1
Adu Cepat Menjawab Soal:

Jawab soal matematika atau IPA pilihan ganda secepat mungkin. Setiap jawaban benar akan memberi dorongan atau tarikan kekuatan ke arah lawan!

2
Hati-hati Jawaban Salah:

Jika salah menjawab, tombolmu akan terkunci selama 1.5 detik sebagai penalti, memberi kesempatan bagi lawan untuk menyerang balik!

3
Kontrol Keyboard di Desktop:

Pemain 1: Tombol A, S, D, F atau 1, 2, 3, 4.
Pemain 2: Tombol J, K, L, ; atau Panah Kiri, Atas, Bawah, Kanan.

4
Kontrol Layar Sentuh (Mobile/Tablet):

Cukup sentuh salah satu dari 4 tombol pilihan ganda. Mendukung Multi-Touch untuk 2 pemain sekaligus di 1 layar HP/Tablet tanpa bentrok!

Pasang RiYooIQ Sekarang

Aplikasi akan terpasang di layar utama HP / desktop Anda dan bisa dimainkan offline kapan saja!

📌 Cara Pasang Manual Berdasarkan Perangkat:

🤖
HP Android (Chrome, Edge, Samsung Internet):

1. Tekan tombol menu titik tiga (⋮) di pojok kanan atas browser.
2. Pilih menu "Install Aplikasi" atau "Tambahkan ke Layar Utama" (Add to Home screen).
3. Aplikasi langsung terpasang di HP Anda lengkap dengan ikon resminya tanpa perlu akun Play Store!

🍎
iPhone / iPad (iOS Safari):

1. Buka game di browser Safari.
2. Tekan tombol Share (ikon kotak dengan panah ke atas di bagian bawah).
3. Gulir ke bawah dan pilih "Add to Home Screen" (Tambahkan ke Layar Utama).

💻
Laptop / Komputer (Windows, Mac, Linux):

Klik ikon monitor kecil atau tanda tambah (➕) di address bar peramban (Chrome / Edge), lalu klik "Install".

📦
Ingin File .APK Mentah?

Game ini 100% PWA-compliant. Anda bisa mengonversi URL PWA ini menjadi file .apk langsung via PWABuilder.com secara gratis untuk dibagikan via WhatsApp atau flashdisk.
